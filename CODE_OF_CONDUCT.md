# Code of conduct

## TL;DR

Be kind. Don't be racist, sexist, or harassing. Disagreements about technical decisions are fine; personal attacks are not.

## Reporting

Email `ffcabbar@gmail.com`. I read every report and act on it.

## Long version

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html). Read the full text there if you want the formal version.

Maintainers reserve the right to remove comments, commits, code, and PRs that don't align with this code, and to ban contributors who make the community unsafe.
